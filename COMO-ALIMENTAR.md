# Onde alimentar cada coisa no SchuleZap

Entre como **responsável/admin** (`DiretoraAna`). Tudo abaixo fica no menu.

## Central da escola
Aba **Central da escola** → três abas dentro:

| Quero cadastrar | Onde |
|---|---|
| **Notas** do boletim | Central → Notas |
| **Prova, tarefa ou evento** (agenda) | Central → Agenda |
| **Turma** de um aluno | Central → Alunos (toque na turma) |
| Ligar **Fala Comigo** para um aluno | Central → Alunos (ícone de balão) |

## Outras abas

| Quero cadastrar | Onde |
|---|---|
| **Aviso da escola** | Aba Avisos → botão "Novo" |
| **Códigos de convite** (novos alunos) | Aba Moderar → Convites → "Gerar 5" |
| Resolver **denúncias** | Aba Moderar → Denúncias |
| Atender **pedidos de ajuda** (Fala Comigo) | Aba Pedidos de ajuda |

## O que o próprio aluno alimenta

| O quê | Onde |
|---|---|
| Post (texto, fotos, enquete) | Mural → caixa de escrever |
| Story (some em 24h) | Mural → "Seu story" |
| Grupo novo | Grupos → "Criar grupo" |
| Foto de perfil, capa, bio | Perfil |
| Mensagem privada | Mensagens |

## Como os dados se conectam

- A **turma** do aluno (Central → Alunos) é o que faz o **aviso** e a
  **agenda** direcionados chegarem só a quem deve. Sem turma, o aluno
  só vê o que é para todos.
- **Disciplina** é criada automaticamente na primeira nota lançada.
- As notas viram a média e a situação na aba **Boletim** do aluno.
